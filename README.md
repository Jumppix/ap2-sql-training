# AP2 SQL-Training

Übungsseite für die SQL-Aufgaben der Abschlussprüfung Teil 2 (Fachinformatiker Anwendungsentwicklung).
31 Aufgaben rund um den Fahrradverleih Elbrad: Auffrischung zu Tabellen, Datentypen und Transaktionen,
danach Abfragen von mittel bis Prüfungsniveau.

- Hinweis und Musterlösung lassen sich je Aufgabe aufdecken.
- Optional kann die eigene Lösung eingetippt oder aus Bausteinen zusammengesetzt werden.
  Sie läuft dann direkt im Browser gegen zwei Testdatensätze und wird mit dem Ergebnis der Musterlösung verglichen.
- Fortschritt und Entwürfe werden im Browser gespeichert (localStorage), also je Gerät und Browser getrennt.
